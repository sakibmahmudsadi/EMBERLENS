# Frontend

Recommended responsibility: map display for the configured demo AOI, sensor and period filters within the fixed window of at most 24 months, monthly burning-activity calendar, source observation inspection, and bounded export UX. Arbitrary AOI drawing/search and long-range analytics are later extensions.

The frontend must consume backend-defined scientific outputs; do not reimplement baselines, anomaly calculations, or sensor-fusion formulas in components. Use real map tiles and real observation layers. Mockups are visual references, not data assets.
