# Sample Data Registry

No sample dataset is included in this starter pack.

When adding a small test/demo fixture, document:
- source/provider and official URL;
- product ID, sensor/platform, collection/version, processing level;
- retrieval date and date coverage;
- AOI and selection method;
- original filename and SHA-256 checksum;
- field schema and row count;
- transformation/method version if derived;
- license/redistribution review;
- limitations and whether values are synthetic or real.

Synthetic test fixtures must be explicitly labeled `SYNTHETIC — NOT NASA DATA` in filenames and documentation.
